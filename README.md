# INSTASCOPE

Analizador de seguidores de Instagram que permite identificar quién no te sigue de vuelta a partir de la exportación de datos en formato ZIP de Instagram.

---

## ¿Qué hace este proyecto?

INSTASCOPE analiza tu archivo de datos exportado desde Instagram (Meta) y te ayuda a:

- Ver quién no te sigue de vuelta
- Comparar seguidores vs seguidos
- Obtener resultados rápidos sin procesos manuales

---

## ¿Cómo usarlo?

### 1. Exporta tus datos de Instagram

Desde el Centro de cuentas de Meta:

- Ve a **Tu información y permisos**
- Selecciona **Exportar tu información**
- Crea una exportación
- Elige tu perfil de Instagram
- Selecciona **Exportar al dispositivo**
- En información específica selecciona:
  - Seguidores
  - Seguidos
- Intervalo de fechas: **Cualquier fecha**
- Formato: **JSON**

---

### 2. Descarga el archivo

Instagram te enviará un archivo ZIP con tu información.

---

### 3. Sube el ZIP

Carga el archivo en INSTASCOPE y obtén los resultados automáticamente.

---

## Notas

- El archivo ZIP debe ser el original descargado de Instagram
- Se recomienda usar formato JSON para mejor compatibilidad
- Funciona mejor con datos completos de seguidores y seguidos
